# SuryaAlert-X: Final Submission

This is the consolidated final submission repository for **SuryaAlert-X**, built for the Bharatiya Antariksh Hackathon 2026 by **Team Temporal Nexus**.

It integrates the "best approach" from our two parallel development tracks into a single unified repository:

1. **The Machine Learning Pipeline (`/ml_pipeline`)**
   Contains the robust Python data engineering, Neupert timing analysis, and model validation scripts developed against real Aditya-L1 (SoLEXS & HEL1OS) data. Includes all generated datasets, reports, and results.
2. **The Command Center Dashboard (`/dashboard`)**
   Contains the state-of-the-art React/Vite interactive frontend, complete with our customized Cyberpunk HUD aesthetics, dynamic state simulation, and the 3D Sun Scanner.

## Directory Structure
- **`ml_pipeline/`** - Data extraction, processing scripts (`01` to `10`), model output, and hackathon presentation files.
- **`dashboard/`** - The final UI, ready for Vercel deployment.

Please refer to the detailed `README.md` and context files within each subfolder for specific setup, run commands, and architecture documentation.
